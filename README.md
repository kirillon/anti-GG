# Вейч — минимизация булевых функций

Локальное приложение с русским интерфейсом. **Ввод только текстовый.** На выходе — диаграмма Вейча с обведёнными группами и минимальной формулой под ней. Диаграмму вместе с формулой можно сохранить в SVG или PNG.

Используется **собственная нейронная сеть на PyTorch, обученная с нуля**. Нет Ollama, готовых моделей, сторонних API, распознавания фотографий или зависимости от GPU. Обученные в этом проекте веса уже находятся в `models/groups.pt`, история обучения и метрики — в `models/groups.json`.

## Запуск

Python 3.10+ и PyTorch (для новых версий PyTorch может потребоваться более новый Python). На этой машине настроено отдельное окружение `.venv`:

```bash
cd /home/starflex/Projects/veitch-minimizer
./run.sh
```

Откройте **http://127.0.0.1:8000**. Для другого порта: `./run.sh --port 8080`. Остановка — Ctrl+C.

Скрипт сам использует Python из `.venv` и работает в bash, zsh и fish без активации окружения. Можно запустить напрямую: `.venv/bin/python app.py`.

Если нужна активация окружения для обучения или тестов, в **fish** выполните `source .venv/bin/activate.fish`, а в **bash/zsh** — `source .venv/bin/activate`. Ошибка `'case' builtin not inside of switch block` означает, что в fish запущен скрипт активации для bash. После неудачной активации команда `python` может использовать системный интерпретатор без PyTorch.

Установка в отдельное окружение на другой машине:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt --index-url https://download.pytorch.org/whl/cpu
./run.sh
```

Интернет нужен только для первоначальной установки PyTorch. Расчёт и обучение выполняются локально.

## Формат ввода

До четырёх разных переменных: `A`, `B`, `C`, `D` или другие латинские буквы с необязательным цифровым индексом (`X1`, `X2`). Регистр не важен. Без объявления переменные сортируются лексикографически; в `F(...)` можно явно задать порядок и сохранить переменные, которые не входят в выражение.

| Операция | Допустимая запись |
|---|---|
| НЕ | `!A`, `¬A`, `~A`, `A'`, `NOT A` |
| И | `A*B`, `A&B`, `A∧B`, `A·B`, `AB`, `A AND B` |
| ИЛИ | `A+B`, `A\|B`, `A∨B`, `A OR B` |
| Исключающее ИЛИ | `A^B`, `A⊕B`, `A XOR B` |
| Константы | `0`, `1` |

Приоритет: НЕ, И, XOR, ИЛИ. Скобки меняют приоритет. `AB` — произведение двух переменных, а не имя одной переменной. Надчёркивание в текстовом вводе заменяется на `!` или `¬`.

Примеры:

```text
A*B + A*!B                 → A
(A+B)*(A+!B)               → A
A^B                       → ¬A · B + A · ¬B
F(A,B,C,D) = !C*!D         → ¬C · ¬D, группа четырёх углов
F(B,A,C,D) = A             → A, порядок осей задаётся объявлением
```

Под «минимальной записью» понимается **минимальная ДНФ**: сначала минимизируется число термов, затем суммарное число вхождений переменных (литералов). Это не поиск самой короткой произвольной формулы с XOR или вынесением множителей. При нескольких равных минимумах показывается один из них. Неопределённые значения (`don't care`) и более четырёх переменных не поддерживаются.

## Как используется машинное обучение

1. Парсер без `eval` строит таблицу истинности.
2. Собственная сеть `16 → 96 (ReLU) → 81 (sigmoid)` оценивает допустимость групп. Вход — 16 значений четырёхпеременной функции; каждый выход соответствует кубу из `{свободно, 0, 1}⁴`. Свободная переменная исчезает из терма. Для меньшего числа переменных таблица дополняется независимыми переменными.
3. Вероятности сети задают порядок рассмотрения групп в точном поиске. Недопустимые группы отбрасываются независимо от уверенности сети. Поиск рассматривает все простые импликанты, поэтому может восстановить пропущенные моделью группы.
4. Точный поиск покрытия с мемоизацией гарантирует минимум по указанному критерию. Нейросеть сама по себе такой гарантии не даёт; её роль — обучаемая оценка групп, а не окончательное доказательство минимальности.
5. Рендерер располагает клетки в порядке Грея `10, 11, 01, 00`. Группы через границы разрезаются на части с одинаковыми стилем линии и номером. Объединение этих частей соответствует одному терму. Под картой отображаются формула и легенда с номерами наборов.

Если файл весов отсутствует, приложение явно сообщает об этом и работает точным алгоритмом. После обучения нужно перезапустить сервер, чтобы подключить новые веса.

## Обучение своей модели

```bash
python train.py --epochs 40 --seed 42
```

Этот скрипт **заново инициализирует случайные веса**, генерирует данные и обучает сеть; готовые веса он не загружает. Модель наследует `torch.nn.Module` и использует `nn.Linear` и `nn.ReLU`. Обучение использует `nn.BCEWithLogitsLoss`, автоматическое дифференцирование PyTorch и `torch.optim.Adam`; батчи формируются через `DataLoader` и `WeightedRandomSampler`. Сеть возвращает логиты, sigmoid применяется только для получения вероятностей при распознавании групп. Входные функции балансируются по количеству единиц, чтобы большие группы встречались достаточно часто.

Данные — полное множество 65 536 булевых функций четырёх переменных. Эталон допустимости группы получается проверкой, что все её клетки равны единице. Разбиение воспроизводимо и не пересекается:

| Набор | Количество разных функций | Назначение |
|---|---:|---|
| Обучающий | 50 000 | Обновление весов |
| Валидационный | 8 192 | Выбор лучших весов по F1 |
| Тестовый | 7 344 | Оценка после завершения обучения |

Результат выполненного обучения на PyTorch 2.14.0+cpu, 40 эпох, seed 42:

- Precision допустимых групп: **1,0**.
- Recall допустимых групп: **1,0**.
- Доля тестовых функций, для которых все 81 решения о допустимости верны: **1,0**.

Это метрики **предсказания допустимых групп**, не метрики самостоятельной минимизации нейросетью. Окончательный ответ проверяет точный алгоритм. Тестовый набор не используется для выбора весов. По валидационному F1 выбрана эпоха 34.

Для отдельного эксперимента, без замены поставляемых весов:

```bash
python train.py --epochs 20 --seed 7 --output models/experiment.pt
```

## Тесты

```bash
python -m unittest discover -s tests -v
```

29 тестов проверяют:

- разбор синтаксиса, приоритет операций, константы, некорректный ввод;
- эквивалентность и минимальность **всех 256 функций трёх переменных** и 204 четырёхпеременных функций по независимому перебору комбинаций;
- сохранение минимума при случайных ошибочных оценках модели;
- пересечения групп, склейку через края и соответствие нарисованных областей термам;
- обновление параметров всех слоёв и уменьшение ошибки при обучении, воспроизводимую инициализацию, сохранение/загрузку весов, отклонение повреждённых параметров, полный цикл обучения и качество на отложенных функциях;
- HTTP API и обработку ошибок.

Проверка в настоящем браузере, если установлены Node.js 22+ и Chromium:

```bash
node tests/browser.mjs
```

Она запускает временные сервер и браузер, проверяет построение карты, ошибки ввода, подключение модели, скачивание SVG/PNG и мобильную ширину. Затем завершает процессы. По умолчанию сервер запускается через `.venv/bin/python`; другой интерпретатор задаётся переменной `PYTHON`. Если Chromium имеет другое имя, задайте `CHROMIUM=/путь/к/chromium`. Для изолированной проверки используется `--no-sandbox`; браузер открывает только локальное приложение. Скриншоты записываются в `artifacts/`.

## Минимизация системы функций — метод меток

Откройте вкладку **«Система функций»**. Выберите 1–4 переменные и задайте 2–4 функции списками номеров единичных наборов. Кнопка **«+ Добавить функцию»** добавляет строку, «−» удаляет. Разделители: запятая, пробел, точка с запятой. Пустая строка или `∅` задаёт нулевую функцию; повторения наборов игнорируются. A — старший бит, далее B, C, D.

Раздел выполняет предоставленный метод меток точным алгоритмом (`veitch/system.py`):

1. Строит все непустые сочетания произведений исходных функций и находит **все** простые импликанты каждого произведения.
2. Объединяет одинаковые импликанты с максимальной меткой — всеми функциями, содержащими эту импликанту.
3. Строит матрицу: столбец соответствует паре «набор / функция», строка — импликанте с меткой. `+` означает поглощение.
4. Точно минимизирует сумму букв **общих** импликант (каждая считается один раз); при равенстве выбирает меньшее число общих термов. `√` отмечает обязательные строки, `*` — остальные выбранные строки. Нижняя строка показывает покрытие столбцов.
5. Для каждого выхода выбирает минимальное число термов из общей выбранной совокупности и выводит ДНФ и итоговую карту.

Ниже отображаются все диаграммы исходных функций и произведений с полными сокращёнными ДНФ; они не называются минимальными, поскольку содержат все простые импликанты. Каждая карта скачивается в SVG. PyTorch продолжает использоваться в разделе одной функции; совместная минимизация следует точному методу меток, без переобучения модели.

**Матрица для Word:** нажмите «Скопировать таблицу для Word», затем Ctrl+V в редакторе и сохраните исходное форматирование. В буфер записываются HTML-таблица с границами и текст с табуляциями. Поддержка вставки зависит от редактора. Резервный вариант — скачать HTML-таблицу, открыть её в Word/браузере или преобразовать текст в таблицу по табуляциям. Для широкой матрицы удобно выбрать альбомную ориентацию страницы.

Предзаполнен пример из задания: F1 = Σ(0,2,4,6,10,12,14), F2 = Σ(2,3,10), F3 = Σ(0,1,2,3,9,11). Результат: **9 строк, 16 столбцов поглощения, 5 выбранных импликант, 13 букв**; 7 исходных/промежуточных карт и 3 итоговых.

Дополнительные тесты проверяют пример задания, все 256 пар функций двух переменных независимым перебором, максимальные метки, нулевые/единичные функции, матрицу и API. Браузерный тест проверяет добавление/удаление функций, HTML в буфере обмена, скачивание таблицы, ошибки и мобильную ширину.

### Оформление по образцу и штрих Шеффера

Карты чёрно-белые, переменные подписаны по краям, отрицания надчёркнуты. Для четырёх переменных строки задают A,C, столбцы — B,D. Порядок номеров:

```text
12 13  9  8
14 15 11 10
 6  7  3  2
 4  5  1  0
```

Матрица имеет объединённый заголовок «Конституента», надчёркнутые буквенные наборы, строку меток Fᵢ и нумерацию столбцов. Иерархия заголовков сохраняется при копировании HTML в Word.

Внизу результата системы приведена реализация **только на двухвходовых элементах Шеффера** (`X ↑ Y = ¬(X·Y)`): определения промежуточных сигналов Tᵢ и система выходов Fᵢ. Одинаковые элементы переиспользуются; специальная минимизация количества NAND-элементов не выполняется. Кнопка копирует весь список определений и выходов. Эквивалентность проверяется по всем наборам, в том числе для нулевых и единичных функций.
